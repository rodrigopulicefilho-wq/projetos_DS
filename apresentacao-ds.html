O que aprendemos

Programar é explicar ao computador, passo a passo, o que ele deve fazer. Foi isso que praticamos.

  • Montar páginas da internet

    Definir o que aparece na tela e como tudo fica bonito.

    HTML e CSS

  • Dar vida às páginas

    Fazer a página reagir quando alguém clica, digita ou toca.

    JavaScript

  • Pensar em objetos

    Organizar um programa como coisas do mundo real, cada uma com suas características e ações.

    Java

  • Desenhar e animar

    Criar imagens, pixel art e movimento direto no navegador.

    Canvas e SVG

  • Incluir todo mundo

    Pensar em quem enxerga pouco, anda mais devagar ou usa só o teclado.

    Acessibilidade

  • Testar, corrigir e publicar

    Achar o que deu errado, consertar e colocar no ar para qualquer pessoa usar.

    Depuração e publicação

Videogame em Java

Em Java, um programa é montado com objetos, como as coisas do mundo real.

Pense em uma forma de bolo. A forma é o molde, e cada bolo feito com ela é um objeto. Aqui, usamos dois moldes: o videogame e o jogo.

Molde: videogame

Ação

Cada objeto guarda seus próprios dados. O botão é uma ação que o objeto sabe fazer.

Semáforo Inclusivo

Um semáforo pensado para que todas as pessoas consigam atravessar a rua com segurança.

  • Mais tempo

    Quem anda mais devagar pode pedir alguns segundos extras.

  • Alto contraste

    Cores fortes e contornos para quem enxerga com dificuldade.

  • Sinal em voz alta

    O computador diz qual é o sinal. Também dá para usar só o teclado.

Vocabulário rápido

Programa
Uma lista de instruções que o computador executa.
Linguagem
O idioma em que escrevemos essas instruções. Usamos Java, JavaScript, HTML e CSS.
Interativo
Que reage ao que a pessoa faz: cliques, toques, digitação.
Acessibilidade
Fazer um produto funcionar para o maior número possível de pessoas.
Pixel art
Imagens desenhadas quadradinho por quadradinho, como nos jogos antigos.
Depurar
Procurar e consertar erros em um programa.

Ferramentas que usamos: OnlineGDB para rodar e depurar Java, GitHub Pages para publicar os sites e o Gemini como IA de apoio.
